Architecture

Built for the real shape of your data

Model the full distribution

Location (μ), scale (σ), skewness (ν), and kurtosis (τ) modeled simultaneously as smooth functions of age, sex, and site.

Permutation Tests

Rigorous non-parametric p-values to evaluate if adding covariates genuinely improves model fit.

Scale to every region

Run base vs. target comparison across all parcels or EEG bands in parallel, with built-in caching.

Zero-shot Site Transfer

Adapt pre-trained reference models to entirely new clinical scanners using only a tiny calibration sample.

site_transfer()

Beautiful Reference Curves

Generate continuous, age-dependent centile bands and calculate exact deviation scores (Z-scores) for individuals.

model.plot_continuous_centiles()

Python Native

R runs the stats via rpy2, but you stay seamlessly in Pandas and Scikit-learn.
